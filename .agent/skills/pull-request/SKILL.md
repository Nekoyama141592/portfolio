# プルリクエスト作成スキル

プルリクエスト（PR）を作成・送信する際は、以下の手順に従うこと。

## 事前チェック：CIの確認

PRを作成する**前**に、ローカルでCIが通ることを確認する。

```bash
npm run check
```

このコマンドは以下の3つのチェックを実行する：

1. **フォーマットチェック** (`npm run format:check`) — oxfmt によるコード整形の確認
2. **リントチェック** (`npm run lint`) — oxlint による静的解析
3. **型チェック** (`npm run astro:check`) — Astro / TypeScript の型チェック

### エラーが出た場合

- フォーマットエラー → `npm run format` で自動修正
- リントエラー → `npm run lint:fix` で自動修正を試み、修正できないものは手動で対応
- 型エラー → コードを修正して再度 `npm run astro:check` で確認

すべてのチェックが通るまでPRを作成しないこと。

## PRの作成

### 言語

- PRのタイトル、本文、コミットメッセージはすべて**日本語**で記述すること。

### PRタイトル

- 変更内容を簡潔に日本語で記述する。
- 例：`トップページのレイアウトを修正`、`ブログ記事一覧の表示を改善`

### PR本文

以下のテンプレートに従って日本語で記述する：

```markdown
## 概要

この変更の目的と背景を記述する。

## 変更内容

- 変更点1
- 変更点2

## 確認事項

- [ ] `npm run check` が通ることを確認した
- [ ] 変更内容をローカルで動作確認した
```

## チェックリスト（最終確認）

PRを送信する前に、以下をすべて確認すること：

- [ ] `npm run check` がエラーなく通る
- [ ] PRのタイトル・本文が日本語で書かれている
- [ ] 変更内容が正しくコミットされている
- [ ] 不要なファイルがコミットに含まれていない
